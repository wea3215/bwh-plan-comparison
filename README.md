## 搬瓦工方案比較：按实际需求筛选

如果你在 Basic、E-Commerce、SLA 和 Ultra 之间犹豫，可以先按这几个问题缩小范围：

1. **预算是首要条件吗？** 先看 Basic 的入门配置和年付价格，再确认对应机房的网络是否满足用途。
2. **访问者主要在中国大陆吗？** 对照 E-Commerce 具体机房的网络说明。线路标签是筛选依据，不是对每个用户都最快的保证。
3. **是否必须部署在亚洲某个城市？** 如果地点是硬性要求，直接比较对应 Ultra 方案的价格和资源。
4. **停机影响是否很大？** 若需要明确的 SLA，再比较 E-Commerce+SLA，并确认地点是官方支持 SLA 的 USCA_5。
5. **资源应该买多大？** 轻量服务可以从较小内存开始评估；数据库、多个站点或较高并发则应结合实际内存和流量需求，而不是只盯 CPU 核数。

需要跨机房迁移时，也先看方案的迁移范围。官方说明 Basic 和 E-Commerce 可在其支持的地点间迁移；Ultra 则按具体地区产品选择。迁移前做好数据备份仍然必要，尤其是运行中的网站或数据库。

## 优惠与结账前检查

本次核验到的官方购物车可以看到套餐配置和价格，但没有足够依据确认一个当前普遍有效的优惠码。因此，不把第三方页面上的旧码当成正在生效的折扣。若结账页出现优惠字段或活动价格，以订单最终金额和适用条件为准。

提交订单前，检查这几项：

- 方案系列和具体数据中心是否选对。
- CPU、内存、存储、月流量和端口是否匹配用途。
- 当前页面显示的是月付、季度、半年还是年付价格。
- 是否存在自动续费或续费价格与首期不同的情况。
- 网络特性和 SLA 是否确实对应你选择的地点。
- 最终账单中的优惠、税费和应付总额。

**简要判断：**预算优先，先比 Basic；更关注机房选择和中国方向网络，逐个核对 E-Commerce 地点；需要官方 SLA，再看 E-Commerce+SLA；部署地点必须在香港、日本或新加坡，则对照相应 Ultra 下单页。选套餐时，地区和线路先于“看起来更大”的配置数字。
